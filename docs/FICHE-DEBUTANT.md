# Fiche pratique AnythingLLM — utilisateur débutant

**Adresse :** https://VOTRE-DOMAINE (communiquée par Charles) — identifiants remis séparément ; changez le mot de passe à la première connexion.

## 1. Les 4 notions
- **Espace de travail (workspace)** : votre dossier de travail avec son propre historique et ses documents. Le vôtre est personnel.
- **Document** : fichier (PDF, Word, texte, page web) que vous ajoutez pour que l'IA s'en serve.
- **Chat** : discussion avec l'IA dans un espace.
- **Fil (thread)** : sous-conversation pour séparer les sujets.

## 2. Premiers pas
1. Connectez-vous, ouvrez votre espace de travail.
2. Cliquez sur l'icône ⬆ « Télécharger un document », déposez vos fichiers, cochez-les, puis **Move to workspace → Save and Embed**.
3. Posez votre question dans le chat, par exemple : « Résume le document X en 5 points ».
4. Les sources utilisées apparaissent sous la réponse : vérifiez-les.

## 3. Modes de chat (⚙ de l'espace > Chat Settings)
- **Chat** : l'IA répond avec ses connaissances et vos documents.
- **Query** : l'IA répond *uniquement* avec vos documents (plus fiable, dit « je ne sais pas » sinon).

## 4. Bons réflexes
- Un prompt précis = une meilleure réponse (contexte, objectif, format voulu).
- Relisez toujours : l'IA peut se tromper.
- Ne mettez pas de données sensibles (santé, mots de passe, données personnelles) sans accord.
- Utilisez un fil par sujet ; bouton « Reset » pour repartir à zéro.
- Un seul espace par projet pour garder des réponses ciblées.
